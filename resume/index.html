Independent engine development

RetroEngine · Solo author · retrogameengine.com

Oct 2025 – present
  • Custom DirectX 12 renderer: I built the full DX12 pipeline from scratch: command queues, descriptor heaps, resource barriers, root signatures, PSO management, and the HDR signal path. There's no engine abstraction layer, and the only third-party dependency is Dear ImGui.
  • Physical CRT simulation: Simulates from first principles, per pixel: beam scanning, phosphor emission and decay, persistence, and glass diffusion. Energy-conserving temporal feedback means persistence never adds energy to the scene. It isn't a post-process filter.
  • Performance on constrained hardware: Holds a stable 60 FPS on an AMD Radeon 660M, a 6-CU RDNA2 integrated GPU in the bottom 10–15% of gaming hardware. That's with the full CRT pipeline, terrain streaming, procedural generation, HDR rendering, and the editor all running, before GPU instancing, frustum culling, or LODs.
  • Shared-ownership texture cache: I redesigned texture ownership from per-chunk allocation to a global shared cache with deterministic key normalization. A 4096×4096 terrain texture is no longer duplicated across every chunk, so memory stays flat no matter how many chunks are loaded.
  • ECS architecture: A component-based entity system with strict GPU resource ownership, deterministic lifetimes, multi-scene loading, safe entity deletion, and serialization to parameter-only scene files.
  • Terrain streaming: Chunks stream in around the camera on procedural terrain. Entire worlds regenerate deterministically from a seed and a small set of parameters.
  • Deterministic simulation time: Pause, rewind, and replay at the engine level. Inputs and scene state scrub along a timeline for debugging and experiments.
  • Editor tooling: A dockable ImGui scene editor with AABB object picking, snapping viewport gizmos, a chunk palette, thumbnails, a construction grid, and live material authoring. A GPU memory debug panel shows live texture memory, SRV usage, and instance counts.
  • Lighting: Directional shadow maps, point lights, volumetric light shafts with depth-based color gradients, atmospheric fog in a single fullscreen-triangle pass, and a separate directional and ambient color model for predictable artistic control.
  • Coverage: Featured on 80.lv and GenerationAmiga, and documented in a series of public dev logs.
